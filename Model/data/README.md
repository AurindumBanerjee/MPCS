# Model/data

Data artifacts used by the models.

- `PresetMemory.txt` — human-readable breakdown of the 30-experience preset
  memory bank (20 novel + 10 repeated variants) used by the preset-memory
  launchers. The executable copy of this bank currently lives inline in
  `../reference/mpcs_preset_memory.py`; this file documents each entry's
  context, action, reward, and intended lesson.
