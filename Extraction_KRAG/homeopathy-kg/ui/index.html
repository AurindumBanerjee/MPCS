🚀 How to Run & Get This Graph

Follow these steps from the project root (homeopathy-kg/) to export data and launch this interactive visualization:

1
Export knowledge graph schemas from extracted JSONL
python ui/export_graph_data.py
Reads data/extracted/run_manual_baseline.jsonl and writes both ui/graph_data.json and ui/data.js across all 20 remedies.
2
Launch the local web server
python serve_ui.py
Starts a local HTTP server on port 8080 serving the interactive studio.
3
Open the interactive studio in your browser
http://localhost:8080/
Use the top-right dropdown to switch between any of the 20 remedies and click any node to inspect textual provenance.

🎨 Knowledge Graph Schema & Visual Grammar

The graph models remedies through a 5-layer multi-relational network:

Medicine (Blue) Central hub remedy entity (e.g., Belladonna, Arsenicum Album).
Physical Symptom (Pink) Somatic symptoms linked via TREATS, classified by anatomical section.
Affective Symptom (Purple) Emotional/mental symptoms linked via HAS AFFECTIVE SYMPTOM.
Modality (Yellow) Environmental factors linked via AGGRAVATED BY or AMELIORATED BY.
Cognitive Domain (Green) RDoC-aligned cognitive domains linked from affective symptoms via MAPS TO.

🧠 Cognitive Domain & Modality Logic

  • Cognitive Domains: Affective symptoms are mapped to 6 domains: Anxiety / Threat Processing, Hyperarousal, Mood / Affect Regulation, Impulse Control / Aggression, Cognitive Processing, and Social Cognition.
  • Modalities: Extracted from general_modality text (polarities: Worse vs Better) and per-symptom aggravating factors.
  • Provenance-Linked: Clicking any node opens the Inspector Drawer showing verbatim quotes from Boericke's text, extraction confidence, and section tags.
